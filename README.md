# Realo

توثيق مبني على PHP و`database.sql` و`config.php`. الاسم في التوثيق السابق: نظام إدارة العقارات (REMS).

## 1 ما هو المشروع

موقع عقارات: الصفحة الرئيسية تعرض عقارات، وصفحة قائمة مع فلترة، وصفحة تفاصيل، وصفحة دخول، ولوحة للمسؤول لإضافة عقار وتعديله وحذفه.

البيانات في `database.sql` تجريبية: شقق وفلل وأرض وعمارة في الرياض وجدة والدمام ومكة.

## 2 لماذا وُجد

التوثيق السابق يصفه منصة أكاديمية لعرض البيع والإيجار والبحث ولوحة مسؤول بسيطة. الكود ينفّذ العرض والفلترة ولوحة الإضافة. لا يوجد تمييز برمجي بين بيع وإيجار سوى نص السعر والوصف في الصفوف المزروعة.

## 3 المستخدمون

| الطرف | السلوك |
| --- | --- |
| زائر | يتصفح `index.php` و`properties.php` و`property.php` بلا دخول |
| مستخدم داخل | الجلسة `$_SESSION['user']` تُنشأ بعد مطابقة اسم وكلمة سر |
| admin | `role = admin` يفتح `admin/dashboard.php` والإضافة والتعديل والحذف |

لا صفحة تسجيل مستخدم جديد. الصف الوحيد المزروع: اسم المستخدم `admin` والدور `admin`.

## 4 القدرات

- عرض أحدث العقارات في الرئيسية.
- فلترة بالموقع (LIKE) والحد الأعلى للسعر ونوع العقار.
- صفحة تفاصيل مع الوصف والصورة.
- دخول وخروج.
- إضافة وتعديل وحذف عقار للمسؤول.
- الصورة مسار نصي يُحفظ في العمود `image` ويُعرض كملف تحت مجلد صور.

## 5 كيف يعمل

`config.php` يفتح `mysqli` إلى القاعدة `realo`. كل صفحة تستدعي `session_start` ثم `config.php` ثم `includes/header.php`. الاستعلامات تُبنى كنص SQL. عرض العناوين يمر على `htmlspecialchars`.

## 6 أمثلة من الكود والبيانات

الدخول في `login.php` يهرب المدخلات بـ `mysqli_real_escape_string` ثم:

```php
SELECT * FROM users WHERE username = '$username' AND password = '$password'
```

المقارنة على عمود `password` كما هو مخزن. ملف SQL يدرج الكلمة كنص صريح في الصف، والتعليق فوق `INSERT` يذكرها. التوثيق السابق يذكر اسم المستخدم `admin` وكلمة المرور ``. الكود يطابق النص المخزن حرفياً. لا `password_hash` ولا `password_verify`.

الإضافة في `admin/add_property.php` تهرب الحقول ثم تدمجها داخل جملة `INSERT` نصية. السعر يُحوَّل بـ `(int)`.

البذرة:

| العنوان | السعر | الموقع | النوع | الصورة |
| --- | --- | --- | --- | --- |
| شقة 3 غرف بوسط المدينة | 450000 | الرياض | شقة | property1.jpg |
| فيلا فاخرة بحديقة | 1200000 | جدة | فيلا | property2.jpg |
| شقة استوديو للإيجار | 2500 | الدمام | شقة | property3.jpg |
| أرض سكنية للبيع | 800000 | الرياض | أرض | property4.jpg |
| شقة 4 غرف راقية | 650000 | مكة | شقة | property5.jpg |
| عمارة للإيجار | 35000 | الرياض | عمارة | property6.jpg |

## 7 رحلة المستخدم

1. فتح `index.php`.
2. الانتقال إلى `properties.php` وتطبيق فلتر GET.
3. فتح `property.php?id=`.
4. `login.php` للمسؤول.
5. `admin/dashboard.php` ثم إضافة أو تعديل أو حذف.
6. `logout.php` يستدعي `session_destroy`.

## 9 الكيانات

### users

`id`, `username` فريد حتى 50, `password` حتى 255, `role` حتى 20 والقيمة الافتراضية في SQL هي `user`.

### properties

`id`, `title`, `price` عدد صحيح, `location`, `type`, `description`, `image`.

لا مفتاح أجنبي بين الجدولين.

## 10 الصلاحيات

صفحات `admin/*.php` ترفض الطلب إن لم تكن الجلسة موجودة أو `role != 'admin'` وتعيد التوجيه إلى `login.php`.

الزائر يرى العقارات. الدخول الناجح لأي دور يضع الصف كاملاً في `$_SESSION['user']` بما فيه عمود كلمة السر. الرأس يظهر رابط اللوحة عندما `role == 'admin'`.

لا صفحة تنشئ مستخدماً بدور `user` رغم أن العمود يقبل هذه القيمة.

## 12 التكامل بين الوحدات

`header.php` يقرأ الجلسة لرسم روابط الدخول أو اللوحة. الصفحات العامة وصفحات الإدارة تشترك في `config.php` ونفس اتصال `$conn`. الحذف والتعديل يعتمدان على `id` في الرابط أو النموذج بعد فحص الدور.

## 14 الأسئلة الشائعة

**ما اسم القاعدة؟**  
`database.sql` و`config.php` يستخدمان `realo`. التوثيق السابق يقول `realo_db`. التشغيل مع الإعداد الحالي يحتاج القاعدة `realo`.

**هل كلمة المرور مجزأة؟**  
لا. الصف المزروع نص صريح، والدخول يقارن النص.

**الصور لا تظهر.**  
SQL يخزن أسماء مثل `property1.jpg`. مجلد الصور غير ظاهر ضمن الملفات الحالية سوى `assets/fonts/OFL.txt`. `login.php` يطلب `assets/images/logo.png` وهذا الملف غير موجود في الشجرة الحالية.

## 18 الواجهة

صفحات عربية. الرأس مشترك. نماذج الدخول والإضافة حقول نصية. الفلتر نموذج GET. التوثيق السابق يذكر بيانات تجريبية فقط.

أيقونة تبويب غير موجودة في الملفات الحالية. الشعار مشار إليه في `login.php` وملفه غير موجود.

## 19 الخادم

صفحات PHP متزامنة. فشل الاتصال يوقف التنفيذ بنص: فشل الاتصال بقاعدة البيانات. لا JSON.

## 20 مسار الطلب

فلترة: GET إلى `properties.php` يبني `WHERE` من الموقع والسعر والنوع ثم `ORDER BY id DESC`.

إضافة: POST من المسؤول، تحقق من الحقول، `INSERT`، توجيه إلى `dashboard.php`.

حذف: `admin/delete_property.php` بعد فحص الدور.

## 21 قاعدة البيانات

`CREATE DATABASE IF NOT EXISTS realo` بترتيب `utf8mb4_unicode_ci`. جدولان بلا علاقات. مستخدم واحد و6 عقارات.

## 24 الأمان الموجود فعلياً

| موجود | التفصيل |
| --- | --- |
| فحص دور اللوحة | مقارنة `role` مع `admin` |
| هروب نصي | `mysqli_real_escape_string` في الدخول والإضافة والفلتر |
| تحويل السعر | `(int)` في الفلتر والإضافة |
| تهريب HTML | `htmlspecialchars` على العناوين والمواقع والأوصاف ورسائل الخطأ |

غير موجود في الكود: تجزئة كلمة السر، واستعلامات محضّرة، وCSRF، وحد للمحاولات، وأيقونة موقع.

جلسة الدخول تخزن صف المستخدم كاملاً ومنه كلمة السر النصية.

التوثيق السابق لا يذكر أن كلمة المرور نص صريح. ملف SQL والتعليق والتوثيق السابق يتفقون على حساب `admin` / `` كنص تشغيل.

## 30 التثبيت

1. Apache مع PHP وMySQL، كما في التوثيق السابق (XAMPP).
2. تنفيذ `database.sql`.
3. الإبقاء على `config.php` أو تعديل المستخدم إن تغيّرت كلمة root.
4. فتح `http://localhost/Realo/` بعد نسخ المجلد إلى مسار يخدمه Apache.

## 31 دليل التطوير

الاستعلامات في الصفحات مباشرة. تعديل عمود عقار يتطلب `database.sql` ونماذج `admin`. الفلتر يقرأ `location` و`max_price` و`type`.

## Quick Start

1. نفّذ `database.sql`.
2. تأكد أن `config.php` يشير إلى `realo` ومستخدم `root` وكلمة مرور فارغة، أو عدّل القيم.
3. افتح `index.php` عبر خادم PHP.
4. ادخل من `login.php` بحساب `admin` / ``.

## For Non-Technical Users

الصفحة الأولى تعرض عقارات جاهزة. صفحة العقارات تضيق النتائج بالمدينة والسعر والنوع. التفاصيل في صفحة كل عقار. إدارة الإضافة والحذف تظهر بعد دخول المسؤول.

## For Developers

افحص `login.php` قبل أي حديث عن تجزئة: المقارنة نصية. افحص اسم القاعدة قبل التشغيل لأن README القديم و`config.php` يختلفان. نماذج الإدارة تبني SQL كنص بعد `mysqli_real_escape_string`. عرض الواجهة يستخدم `htmlspecialchars`.
